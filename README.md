# mytool

## 概要
このリポジトリは、Windows 環境で使う  
**個人向けの軽量コマンド／ランチャツール群**です。

- バッチファイル本体は `cmdsrc`
- 実行用ショートカットは `cmd`
- クリップボード用テキストは `c`

という役割分担で構成されています。

---

## 目的
- 作業をできるだけ **短い操作**で行う
- 毎回同じ操作・入力を **繰り返さない**
- 環境が変わっても **コピペで持っていける** 形にする

個人利用を前提としたツール群です。

---

## フォルダ構成

```text
mytool
├─ cmd       # 実行用ショートカット置き場（PATH に追加）
├─ cmdsrc    # バッチファイル本体
└─ c         # クリップボード用テキスト置き場
```

---

## 各フォルダの役割

### cmd
- 実行用ショートカット（`.lnk`）を配置
- このフォルダを PATH に通して使用します

### cmdsrc
- 実体のバッチファイルを配置
- 主な役割
  - `c.bat`：クリップボード操作
  - `f.bat`：フォルダ・URL・補助ツールのランチャ

### c
- `c.bat` で使用するテキストファイル置き場
- 生成 AI 用の定型プロンプトや定型文などを想定

---

## セットアップ概要

1. `cmdsrc` 内の `.bat` に対してショートカットを作成
2. ショートカットを `cmd` フォルダに配置
3. `cmd` フォルダを PATH に追加
4. コマンドとして実行

詳細は各フォルダ内の README を参照してください。
