# c

## 概要
このフォルダは、`c.bat` で使用する  
**クリップボード用テキストファイル置き場**です。

主に以下のような用途を想定しています。

- 生成 AI に渡す **定型プロンプト**
- よく使う定型文やメモ
- 作業中に一時的にコピーしたいテキスト

---

## 使い方

1. このフォルダに `.txt` ファイルを置く
2. コマンドで実行する

```text
c sample
```

3. `sample.txt` の内容がそのままクリップボードにコピーされます

---

## 想定している使い道

- 生成 AI 用のプロンプトテンプレート
- 毎回手入力したくない文章
- 作業時の一時メモや個人用テキスト

※ このフォルダは **ローカル環境での個人利用**を前提としています。
