# cmd

## 概要
このフォルダは、実行用バッチファイルの**ショートカット（.lnk）置き場**です。  
PATH を通すことで、どこからでもコマンドとして呼び出せるようにします。

---

## セットアップ手順

1. `cmdsrc` フォルダ内の `c.bat`、`f.bat` に対してショートカットを作成します。
2. 作成したショートカットの名前を、それぞれ以下のように変更します。
   - `c.bat` → `c`
   - `f.bat` → `f`
3. この `cmd` フォルダを **PATH 環境変数**に追加します。

---

## 実行方法

### コマンドプロンプトから
```text
c xxx
f c
```

### Win + R から
```text
f f
```

※ Win + R からの実行は、ショートカット経由での利用を想定しています。

---

## 補足
- 実体のバッチファイルは `cmdsrc` フォルダにあります。
- 本フォルダ（`cmd`）にはショートカットのみを配置してください。
